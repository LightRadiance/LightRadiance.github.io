PER 几乎是深度强化学习的默认组件。理由很直观：TD 误差大的样本“更值得学”，优先回放它们，价值函数应该收敛得更快。这个叙事在 Atari 上被反复引用，但它其实依赖一个很强的假设——优先采样高 TD 样本，会加速全局的价值传播。

我想把这个假设单独拿出来，在一个没有神经网络、没有函数逼近误差的环境里检验。如果 PER 的加速来自“更好的样本顺序”，那么在最干净的表格环境里，它应该更明显；如果连这里都看不到稳定的加速，那我们对它在深度 RL 中的加速叙事就需要更谨慎。

这篇文章总结我在 PER-reeval 项目里的一组实验。结论先行：在这个受控设定下，我没有观察到 PER 对 MSVE 收敛的稳定加速。PER 的加速与重要性采样（IS）的阻尼之间存在一个结构性矛盾：去掉 IS 才快，但去掉 IS 又不稳定。我据此尝试了逆频率采样；它在表格链上有效，但在神经网络上失效。整体上，这是一次失败的尝试。

## 1. 问题：PER 的加速从哪里来？

PER 给每个转移一个优先级 `p_i = (|TD_i| + ε)^α`，采样概率正比于优先级，再用重要性采样权重 `w_i` 修正非均匀采样带来的偏差。它的默认叙事是：高 TD 的样本包含更多“意外”，所以更值得回放。

但 TD 误差是一个局部量。它只说明“当前这一步的估计与自举目标不一致”，并不说明“这次更新对全局 MSVE 的贡献有多大”。在一条稀疏奖励的长链上，价值需要从终点一站一站地向后传播；此时真正重要的是“下一个应该被更新的状态在哪里”，而不是“哪个状态的 TD 绝对值最大”。这两者并不总是一回事。

所以我把问题拆成三个可检验的小问题：

1. 在表格链上，PER + IS 是否比均匀回放（uniform）更快地把 MSVE 降到同一水平？
2. 如果去掉 IS，加速是否出现？代价是什么？
3. 如果 PER 的优先级不适合这个任务，是否存在更简单的替代？

## 2. 实验设置

主实验是一条 50 状态的确定性马尔可夫链：从 `s1` 出发，动作只有向左、向右，只有走到 `s50` 才得到 +1 的奖励，其余转移奖励为 0；折扣因子 `γ = 0.99`，单回合上限 500 步。值函数用表格 Q-learning 学习，学习率默认 0.1，ε 从 1.0 线性衰减到 0.05。

| 项目 | 设置 |
| --- | --- |
| 环境 | MarkovChain-v0，50 状态，稀疏奖励，确定性转移 |
| 算法 | 表格 Q-learning，γ = 0.99，lr = 0.1（另有说明除外） |
| 采样 | uniform / PER（α = 0.6，β: 0.4 → 1）/ PER 无 IS（β = 0）/ 逆频率 |
| batch | 1、8、32、64 |
| 种子 | 10 个 |
| 预算 | 60k 环境步，每 1k 步评估一次 |
| 指标 | MSVE：`V(s) = max_a Q(s,a)` 与真实 `V*(s)` 在 49 个非终止状态上的均方误差 |

选择表格链的原因不是它“简单”，而是它干净：没有函数逼近误差，没有网络初始化，没有泛化；Q 表的每个状态是独立的参数，任何性能差异只能来自采样顺序和更新幅度。MSVE 可以直接对真实值计算，不需要估计。换句话说，这是一个可以把“PER 的优先级是否真的有用”单独隔离出来的环境。

所有对照组共享同一份数据、同一个探索策略、同一个评估网格；唯一的区别是采样方式。这是我认为这组实验最有价值的地方：它把变量降到了一个可以解释的程度。

需要提前说明一个混杂因素：在稀疏奖励下，“首次发现奖励”的时间本身有很大的种子方差，而它和“发现之后价值传播多快”是两件事。所有绝对收敛步数都混合了这两个成分。后文会用一个粗略的对齐来分离它们，但这个混杂不能被完全消除。

## 3. PER + IS：没有稳定加速

图 1 是主结果。四个 panel 分别是 batch 1、8、32、64。最直接的观察是：PER + IS 在任何一个设置里都没有出现稳定的、大幅的加速。

- **batch 32**：uniform 在 8.0k 步达到 MSVE < 1e-2；PER + IS 在 19.5k 步，约 2.4 倍。10 个种子里 PER 有 8 个达到阈值，而这 8 个全部比 uniform 慢。
- **batch 64**：中位数是 19.5k 步对 10.0k 步。但逐种子比较时，10 个种子里有 5 个 PER 更快——这一格的差异对种子很敏感。按整条曲线的积分（时间平均 MSVE），PER 仍然更差：0.145 对 0.083。所以更准确的说法不是“PER 一定更慢”，而是“没有稳定加速，且中位表现更差”。
- **batch 8**：PER + IS 没有一个种子在 60k 内达到 1e-2，最终 MSVE 的中位数停在 0.194；uniform 是 23.5k 步、10/10。
- **batch 1**：把学习率从 0.1 提到 1.0，uniform 10/10 在 37k 达到阈值；PER + IS 仍然 0/10，停在 0.605 附近。

batch 1 的结果值得单独说。batch 1 时一个 batch 只有一个样本，不存在“同一转移被重复抽中”带来的有效步长放大；IS 权重的阻尼因此更直接地暴露出来。把 lr 提高 10 倍，PER 的最终 MSVE 只从 0.637 变到 0.605，几乎没有被拉回来；而 uniform 在同样的 lr 下 10/10 收敛。这说明阻尼不是靠简单调大学习率就能抵消的。

## 4. 矛盾：IS 的阻尼

标准 PER 的 IS 权重是

`w_i = (N · P(i))^(-β) / max_j (N · P(j))^(-β)`

其中 `P(i)` 是转移 `i` 被采样的概率，`N` 是回放池大小。这个归一化的目的是让最大的权重等于 1，从而保证更新幅度不超过名义学习率。但在 β = 1 时，它可以写成更直观的形式：

`w_i = p_min / p_i`

优先级越高，权重越小。一个 TD 误差很大的“波前”样本，恰恰是 PER 最想回放的样本，也是权重被压得最小的样本。

如果波前的 TD 是最小值的 100 倍，α = 0.6 时 `w ≈ 0.063`；1000 倍时 `w ≈ 0.016`。在 b64 的一次探针里（seed 0），落在波前 ±1 的样本，IS 权重的中位数是 **0.035**，10% 分位是 0.018；作为对照，uniform 的权重恒为 1。按名义 lr = 0.1 计算，PER 在波前的有效步长约 **0.0035**，比 uniform 小近 30 倍。

这就形成了一个矛盾的局面：PER 用更高的采样频率来补偿，但采样频率的提升受 batch 大小约束，而权重阻尼是乘性的、持续的。两者相抵，净更新量反而更小。β 从 0.4 退火到 1 的过程，也是阻尼逐渐加深的过程；而价值传播最活跃的阶段正好落在这段退火区间里，步长被持续压低。

这里需要澄清一点：IS 保证的是“期望更新方向”无偏，不是“更新幅度”不变。最大权重归一化把所有样本的权重压到 1 以下，在平均意义上把整个更新的尺度压小了；固定点不变，但到达固定点的速度变慢。这不是 IS 的数学必然，而是标准实现为了稳定性做的选择。如果改成按期望权重归一化，平均权重会回到 1，但方差通常会更大；我没有系统比较这种变体，所以不能把问题完全归咎于 IS 本身。

但至少在这个实现、这组实验里，阻尼是解释“PER 为什么没有加速”的最直接机制。

## 5. 去掉 IS：加速出现了，但代价是稳定性

<figure>
  <img src="{{ '/assets/images/per-reeval/fig2-no-is.png' | relative_url }}" alt="去掉 IS 后 PER 在 batch 8 和 batch 64 上的 MSVE 曲线">
  <figcaption>图 2：去掉 IS 后的 PER。细线是单个种子，粗线是收敛种子的中位数；× 标记发散种子的曲线终点。panel (a) batch 8 上 no-IS 明显更快；panel (b) batch 64 上 3/10 个种子发散，7/10 个收敛种子的中位收敛时间为 16k。b64 的 no-IS 即使最终收敛，也可能出现暂时的值震荡（约 20k 处的尖峰）。</figcaption>
</figure>

如果 IS 是阻尼的来源，那么把 β 设为 0、完全去掉 IS，应该能看到 PER 的“原始速度”。实验结果确实如此，但只在很窄的窗口里成立。

- **batch 8**：no-IS 在 12.5k 步达到 1e-2，uniform 是 23.5k，约 1.9 倍；10/10 收敛。这是整个项目里 PER 的优先级唯一一次带来明确的、端到端的加速。
- **batch 32**：no-IS 是 11.0k，uniform 是 8.0k，反而更慢。用 MSVE 首次低于 0.6 粗略标记“发现奖励”，no-IS 的发现后传播阶段更快（1k 对 2.5k），但发现本身更晚（10k 对 5.5k），净效果仍然是更慢。
- **batch 64**：no-IS 是 16.0k，uniform 是 10.0k；7/10 收敛，3/10 发散。
- **batch 8、lr = 0.5**：no-IS 是 14.0k（8/10），uniform 是 17.0k（10/10）；2/10 发散。

发散不是偶然。在 b64 的一次探针里，同一个 `(s, a)` 在一个 batch 内被重复抽中的次数：中位数 7，90% 分位 24，最大 52；22% 的 batch 至少重复 10 次。按 lr = 0.1 计算，最坏情况下的有效步长是 5.2，超过 `2 / (1 + γ) ≈ 1.005` 这个粗略的稳定边界。b8、lr = 0.5 时，重复次数的上限是 8，有效步长最高 4.0，也越过了边界。

这解释了为什么 no-IS 的加速总是和发散风险绑在一起：它的“快”不是因为它找到了更好的样本，而是因为同一个样本在一个 batch 里被更新了多次，等效于放大了学习率。它和稳定性是同一枚硬币的两面。IS 的作用正是把这枚硬币压回稳定的一面；但它同时也把加速压没了。

需要说明的是，`2 / (1 + γ)` 只是一个粗略的方向性边界，不是充分条件。有效步长的估计并不能单独预测哪个种子会发散；是否发散还取决于哪些状态被重复、当时的值偏差有多大、以及重复是否形成正反馈。但这个边界与观察到的发散方向是一致的。

## 6. 为什么：TD 误差是局部的

把上面的现象放在一起，可以得到一个比较清楚的图景。

TD 误差度量的是“这一步的自举目标与当前估计差多少”。它是一个局部量，不知道这次更新对全局 MSVE 的贡献。EVB（expected value of backup）的概念来自 Mattar 与 Daw 对规划中记忆回放的规范性解释。Li 等人在 2021 年的工作里进一步证明：在 Q-learning 中，TD 误差的绝对值给出了 EVB 的一个上界（差一个步长因子）；在他们的线性网格例子里，按 TD 优先级需要 4N 次回放，按 EVB 只需要 N 次。TD 会把“非最优动作”的经验也排得很高，因为它同样能产生大的残差。

真正能加速全局传播的，是“这次 backup 能让多少状态的值向前推进”。Prioritized sweeping（Moore & Atkeson, 1993）用模型和优先队列来做这件事：它知道状态之间的前驱关系，可以把更新直接推向波前。PER 没有模型，只能从回放池里抽样；它的优先级还是上一次更新时算出来的，可能已经过时。两者在机制上并不是一回事。

我们的 no-IS 结果和这个区分是一致的：去掉 IS 后，PER 在“发现之后的传播阶段”确实更快，但它没有把这种局部优势转化为端到端的加速——发现更晚、且更容易不稳定。PER + IS 则连局部优势都被阻尼抵消了：在 b32 上，发现后的中位传播时间是 11.5k，uniform 是 2.5k。

需要区分的是：在这组实验里，端到端变慢的直接原因是 IS 阻尼；TD 的局部性更多解释了为什么 PER 的优先级不能无条件地转化为全局加速。两者并不矛盾，但主次不同。

我还做了一个单种子探针，记录每一步被采样到的状态，并用当前值与 `V*` 的偏差定义波前。在 PER 的传播阶段，采样倾向于在已收敛的一侧堆积，看起来像在“追尾巴”。但这个探针没有按发现时刻对齐，也只有一个种子；我只把它当作一个提示，不作为定量结论。真正支撑主结论的，还是前面的 MSVE 对照和 IS 权重测量。

## 7. 一个替代尝试：逆频率采样

如果问题的一部分是“访问频率偏斜”——靠近起点的状态被反复访问，波前附近的状态很少被看到——那么一个自然的替代方案是：不要按 TD 误差采样，而是按状态的逆频率采样。

具体做法很简单：对回放池里的每个状态 `s`，记它在池子里的转移数为 `B(s)`；采样时先在所有出现过的状态上均匀抽一个状态，再在这个状态的转移里均匀抽一条。这样每条转移被抽中的概率正比于 `1 / B(s)`，每个状态获得的总采样质量相同。权重恒为 1，不需要 IS。

```text
for each stored transition i: s_i = state(obs_i)
sample s ~ Uniform({s : B(s) > 0})
sample i ~ Uniform({i : s_i = s})
update Q with weight 1
```

它和 uniform 的区别在于：uniform 是按“转移”均匀抽，访问频繁的状态自然占更多样本；逆频率是按“状态”均匀抽，把每个状态的更新预算拉平。在表格 Q-learning 里，每个状态的 Q 是独立的参数，所以“每个状态获得相同的更新次数”是一个很自然的目标；在这个目标下，状态均匀采样就是目标分布本身，不需要再用 IS 把它拉回访问分布。

### 表格环境：有效

在表格链上，逆频率采样的效果是明显的：

- batch 1：35.5k（8/10）对 uniform 的 56.5k（2/10）；
- batch 8：11.0k 对 23.5k；
- batch 32：4.0k 对 8.0k；
- batch 64：7.5k 对 10.0k。

在能配对的种子里，batch 8 有 9/10、batch 32 有 8/10、batch 64 有 7/10 更快。batch 1 的 uniform 本身很慢（lr = 0.1 只有 2/10 达到 1e-2），所以这一行更多说明逆频率能让多数种子在预算内完成，而不是一个干净的 2 倍加速。

为什么它在表格里有效？因为在表格 Q 中，状态之间没有共享参数；把更新预算从“被访问得多的状态”挪到“被访问得少的状态”，不会伤害已经学会的状态，也不会引入 IS 的方差。它纠正的是一个纯粹的数量偏斜，而不是试图估计“哪个样本更有价值”。

但即使同为表格环境，这个结论也不是普适的。我在一个 7×7 网格世界上跑了同样的对照（1M 步，lr = 5e-4）：batch 32/64 上逆频率更快，batch 8 上反而略慢于 uniform；PER + IS 仍然是最慢的。排序依赖状态访问结构，所以我不把“逆频率更好”当作一条普遍规律。

### 神经网络：优势消失

<figure>
  <img src="{{ '/assets/images/per-reeval/fig3-invfreq.png' | relative_url }}" alt="逆频率采样在表格链、DQN one-hot 链和 FrozenLake 上的 MSVE 曲线">
  <figcaption>图 3：逆频率采样从表格到神经网络的迁移。(a) 表格链 batch 32 上明显更快；(b) 把 Q 表换成 32×32 MLP、输入 one-hot 后，二者基本重合；(c) FrozenLake 8×8、lr = 1e-4 上，逆频率反而更差；(d) lr = 1e-3 时，逆频率在早期更快，但最终平台更高。纵轴对数，阴影为四分位区间。</figcaption>
</figure>

把 Q 表换成神经网络之后，情况变了。

- **DQN，one-hot 链**：uniform 在 36.5k 达到 1e-2，逆频率是 37.5k；最终 MSVE 分别是 `2.3e-5` 和 `3.3e-6`。基本打平：逆频率的最终误差略低，但收敛时间没有优势。
- **DQN，FrozenLake 8×8，lr = 1e-4**：uniform 43.0k（9/10），逆频率 52.5k（6/10）；最终 MSVE 是 `5.2e-6` 对 `1.0e-3`。逆频率不仅没有优势，反而更差。PER 在同一设置下也只有 3/10 达到 1e-2，最终 MSVE 约 0.108。
- **FrozenLake，lr = 1e-3**：逆频率在早期更快（19.0k 对 33.5k 达到 1e-2），但最终 MSVE 是 `2.2e-3` 对 `2.9e-4`，平台更高。它买到的是早期的误差下降，不是更好的最终精度。

也就是说，逆频率采样在表格里是一个有效的对照，但它没有通过神经网络的检验。这次尝试作为“PER 的通用替代”是失败的。

为什么？我能给出的只是一些假设，而不是结论：

1. 函数逼近把状态耦合在一起。更新一个状态会改变很多状态；在表格里“每个状态获得相同更新次数”等于“每个状态获得相同进度”，在神经网络里这个等式不成立。
2. 逆频率按状态访问频率分配预算，但网络真正关心的是梯度的方向和特征干扰；稀有状态可能噪声很大，也可能对常见状态没有帮助，过度采样它们反而有害。
3. 表格里的优势依赖于 Q 表的独立性；一旦有了共享参数，这个前提就消失了。

这些假设需要更大的网络、更多的环境和更细的梯度诊断才能验证。至少在这组小规模实验里，逆频率的优势没有出现。

## 8. 讨论与限制

这次失败说明了什么？

- **PER 的加速不是无条件的。** 它依赖 IS 的关闭、batch/lr 的特定窗口，以及表格环境的独立性假设。这些条件在深度 RL 中很少同时成立。
- **IS 的归一化和 β 调度不是装饰。** 它们直接决定你有没有加速：去掉 IS 可能变快，但也会把稳定性一起拿走；保留 IS 则可能把加速全部阻尼掉。调 PER 的时候，这两个旋钮值得单独检查。
- **事后看，逆频率采样更像一个诊断工具，而不是通用替代。** 它说明表格链上的一个瓶颈确实是状态访问频率不均；但它没有把这种优势带到函数逼近中。
- **负结果的价值在于排除解释。** 它不能证明“PER 在深度 RL 中没用”，但可以说明“优先采样高 TD 样本就会加速全局收敛”这个简单叙事，在这个干净设定下不成立。

这组实验的限制也很清楚：

- 主实验只有一条 50 状态的确定性链；稀疏奖励、表格 Q、10 个种子。另一个网格环境的排序不稳定，说明结论对状态访问结构敏感。
- 所有收敛步数都混合了“探索发现奖励”和“价值传播”；我用 MSVE 首次低于 0.6 做了一个粗略对齐，但它不是精确的发现时刻，也没有多 seed 的探针支持。
- 我没有做 β 的固定/退火消融，也没有系统扫描 dense reward、随机转移、更大的链；因此不能把“阻尼”和“β 调度”完全分开。
- 神经网络实验规模很小（32×32 MLP、60k 步、10 seeds、没有超参搜索）。逆频率在 NN 下失效，不能据此断言它在所有 NN 设定下都无效。
- MSVE 是价值误差，不是回报或策略性能。PER 可能通过改变数据分布影响探索和策略，即使 MSVE 没有更快。

如果重做，我会先补三件事：记录每个 seed 首次到达终点的时刻，用真正的 discovery-aligned 曲线替代粗略对齐；做 β 的固定/慢退火消融，把“权重幅度”和“退火调度”分开；在 NN 里加一个线性 one-hot 的桥接组，看看优势是在哪一步消失的。

## 9. 结论

如果只用一句话总结：在这个表格链上，PER 没有兑现“加速 MSVE 收敛”的承诺；它要么被 IS 的阻尼抵消，要么在去掉 IS 后以稳定性为代价换取有限的加速。逆频率采样在表格里是一个有效的对照，但它没有通过神经网络的检验。这次尝试整体是失败的；我把失败的过程和边界条件记录下来，供以后参考。

这不是说 PER 在深度 RL 中没有价值。它可能通过其他机制起作用：改变数据分布、稳定训练、间接影响探索。本文检验的是一个很具体的命题：在表格链上，PER 是否加速 MSVE 收敛。答案是否定的；至少，不是稳定的、大幅的加速。
