# 我的第一篇文章

这是你的第一篇文章，直接用 Markdown 写正文即可。

## 怎么发布一篇新文章？

1. 在 `_posts` 文件夹里新建一个文件，文件名格式必须是：
   `年-月-日-文章名.md`，例如 `2026-09-20-my-second-post.md`
   （**文件名用英文或拼音**，不要用中文，否则网址会很难看）
2. 在文件最上方加上这样的头信息（front matter）：

   ```
   ---
   layout: default
   title: 文章标题
   date: 2026-09-20
   ---
   ```

3. 把头信息下面的内容换成你的正文（就是你现在看到的这些文字）。
4. 提交并推送到 GitHub，一两分钟后文章就会自动出现在网站首页的文章列表里。
